Rosetta Stone

Reading a worktree row.

Every worktree row across both presentations carries the exact same six pieces of metadata in strict order. Cards unpack them onto dedicated lines; the list condenses them into 40 columns.

01 · AGENT ◆
02 · REPO marketplace-billing-service
03 · BRANCH · worktree-WAYF-20748
04 · GIT ↑3 ✱3
05 · LOCATION ·here
06 · PULL REQUEST ⧗

01 Agent State

Leading glyph: ◆ blocked (needs attention!), ● working, ✔ done, ○ idle, · open with no agent, or ◌ dimmed checkout that exists on disk but is not open in Herdr.

02 Repository

Repository name as detected from Git root, or directory basename if detached. Names dynamically dictate card row widths to prevent truncation.

03 Branch Name

Displayed only when different from the feature's own name (ticket groups omit redundant branch names to conserve horizontal columns).

04 Git Porcelain Status

↑3 commits ahead, ↓2 behind, ✱3 modified/staged paths, !2 merge conflicts. A completely quiet tree means Git is clean.

05 Current Location (·here)

Marks the exact worktree workspace hosting the active Wayfindr sidebar pane.

06 Pull Request Status

Trailing mark: ✔ merged (purple), ⧗ in progress (U+29D7 hourglass, not wide emoji), ✕ closed (red).

01

Grouped by feature, not by repo.

A single Jira ticket or release often touches an API gateway, a billing service, frontend components, and Terraform manifests. In Herdr's standard sidebar, these checkouts scatter across four separate repository roots. Wayfindr unifies them under one cohesive ticket heading with stable color hashing.

02

Two views, one continuous state.

Press v anytime to toggle between a 40-column hierarchical tree list and an ergonomic card grid. Cards are dynamically sized to the longest repository name in each row, packing neatly without truncating long names like marketplace-billing-service into credit-deci….

View presentationlist ⇄ cards (v)
Row width packingwidest name in row
Touch / Mouse aim1st click aims, 2nd fires
03

One sort rule across both levels.

Press s to cycle six deterministic sort orders: alpha, status, and agent (ascending then descending). Both top-level feature groups and the worktrees inside them follow the exact same ordering rule, so the answer to "what should I inspect first" is always consistent.

status ascblocked > working > done > idle
agent ascmost recently active first
Ungroupedalways sinks to bottom
04

Pull-request states without polling.

Pull requests are queried via direct GitHub GraphQL queries in a decoupled second pass after the initial UI frame paints. A feature is marked merged only when every checkout under it has a merged PR. Merged PR answers are permanently cached in memory for the life of the pane session.

Query engineGitHub GraphQL
Merged cacheimmutable in-memory
Background timer0 loops · 0% CPU
05

Agents counted, not just named.

A card says 2 agents working rather than a vague working, and counts agents in the state it is naming. A feature labelled blocked because one agent halted reads 1 agent blocked even with other agents actively typing. The most urgent state bubbles up to folded headers automatically.

Urgency rollup◆ 1 blocked (visible when folded)
Active count● 2 working
06

Left-edge docking & singleton sweep.

Herdr only splits right or down without width arguments. Wayfindr uses an ingenious left-edge placement swap hack and calculates its split ratio dynamically via Herdr's layout socket API. Opening the sidebar closes any orphan sidebar left behind in other workspaces, following your focus cleanly.

$herdr-wayfindr --list
Deterministic Business Logic

Grouping Precedence Hierarchy

When collecting worktrees, the resolver evaluates each checkout through five strict rules. The first rule that matches claims the worktree.

01 Explicit Tag (t) Assigned manually with t key, right-click, or --tag. Keyed by absolute worktree path in groups.json; survives branch renames and Herdr restarts.
02 Ticket Key Pattern Matches Jira / issue ticket keys (e.g. WAYF-20748). Scans branch name first; if missing or detached, scans Herdr workspace name. Uppercased automatically.
03 Branch Pattern Regex User-configured custom regular expressions in config.toml using named capture groups: (?P<group>...).
04 Shared Directory Name Checkout directory name shared by worktrees across two or more distinct repository roots.
05 Ungrouped Fallback Any worktree that matches none of the above. Defaults to folded, and always sinks to the bottom regardless of sort order or direction.

Group Header Renaming (R): Pressing R renames only the visual display label of a group without changing its underlying key or worktree member assignments.

Keyboard & Mouse Reference

Everyday Controls

Wayfindr is keyboard-first. Arrows and hjkl move consistently everywhere.

Key List Mode Cards Mode
j / k Move cursor down / up one row Move down / up one card row
h / l — Previous / next card in current row
enter Jump to worktree (opens workspace if needed) Open feature (level 1) or jump to worktree (level 2)
space Fold / unfold focused group Press / activate focused card
v Switch to Cards view Switch to List view
s Cycle sort order: alpha asc → alpha desc → status asc → status desc → agent asc → agent desc
t Tag selected worktree into a group (empty name clears tag)
p Pin derived group as an explicit tag on this checkout
R Rename group header label (empty name resets to derived)
r Refresh world state immediately (zero periodic polling)
esc / q Close sidebar pane Back out of feature to level 1, then close pane
Right Click Context-sensitive menu: worktrees (Open, Tag, Pin) · groups (Open, Rename, Fold/Unfold, Delete All)

Install Wayfindr

Install directly via the Herdr plugin manager. Open it with a single keybinding from any workspace.

$herdr plugin install echeble/wayfindr

Recommended Global Keybinding

Add this to your Herdr configuration (~/.config/herdr/config.toml) to toggle the feature sidebar from anywhere with cmd+shift+f: 

[[keys.command]]
key = "cmd+shift+f"
type = "plugin_action"
command = "echeble.wayfindr.toggle"
description = "toggle the feature sidebar"

Publish $group Metadata to Herdr's Native Sidebar

Wayfindr publishes each workspace's group as a $group token. Add it to Herdr's row template so spaces show their feature group even when the sidebar pane is closed: 

[ui.sidebar.spaces]
rows = [["state_icon", "workspace"], ["branch", "git_status"], ["$group"]]

Then run herdr server reload-config.

Headless CLI Flags

The binary functions cleanly outside the pane via Herdr's socket API: 

herdr-wayfindr --list                      # Print text grouping, rules, and PR state
herdr-wayfindr --tag WAYF-20748             # Tag focused workspace's checkout
herdr-wayfindr --rename WAYF-20748 "Billing" # Retitle visual group header
herdr-wayfindr --report-tokens             # Restamp $group metadata tokens in Herdr

Building from Source & Linking

For local development: 

git clone https://github.com/echeble/herdr-wayfindr ~/wayfindr
cd ~/wayfindr
go build -o bin/herdr-wayfindr ./cmd/herdr-wayfindr
herdr plugin link ~/wayfindr
herdr plugin list --plugin echeble.wayfindr --json
